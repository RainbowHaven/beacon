# Beacon / Rainbow Haven design system

Calm nonprofit operations dashboard. Not craft-paper, not rainbow-washed SaaS.

## Identity

- NGO: Rainbow Haven. Product: Beacon.
- Header: full logo (rainbow + house + RAINBOW HAVEN wordmark). Use the supplied Brand Asset exactly. Never initials, emoji, invented SVG, or the word “Beacon” as a logo.
- Title/footer: Beacon.
- Dark mode: logo sits on a white/light rounded chip. No invert filter.
- Do not use the six rainbow stripe colours anywhere except the logo.

## Type and space

- System font stack, 16px body, 14px minimum chrome, 16px inputs, H1 1.75rem.
- Spacing scale 4/8/12/16/24/32/48px. Generous whitespace.
- Flat, high contrast. WCAG AA. Off-white `#F4F6F6`, ink `#012A2C`, primary `#0F5F5A`.
- Dark: page `#0F1A1A`, text `#E8EEEE`, primary `#4AA79F`.

## Components (daisyUI vocabulary)

Buttons: one `btn-primary` per view; others outline/ghost.
Alerts for flash/errors.
Tables on desktop; cards/list rows on mobile.
Dock bottom nav on mobile (Occupants, Expenses, Reports, More); drawer sidebar on desktop with the logo at the top.

## Audience

Safe-house managers, not 20-year-olds. Large tap targets (44px), no tiny type.
